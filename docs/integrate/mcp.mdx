Supercharge your AI agents with Claidor as a Model Context Protocol (MCP) server.

## What is MCP?

MCP is a protocol for integrating tools with AI agents. It can greatly enhance the capabilities of your AI agents by providing them with real-time data and context.

Claidor offers a remote MCP server that you can connect to from most AI clients.

## How does it work?

You need a MCP-capable agent environment to use Claidor over MCP. A few of them are Claude Desktop and Cursor.

## Connecting to Claidor MCP

Claidor provides two MCP servers:

- **Production**: `https://mcp.claidorhq.com/mcp/claidor-mcp` - Connect to your live Claidor organization
- **Sandbox**: `https://mcp.claidorhq.com/mcp/claidor-sandbox` - Connect to the Claidor sandbox environment for testing

When you can specify a MCP URL, use one of the URLs above depending on your environment.

If you have to specify a command, use:

```json
{
  "mcpServers": {
    "Claidor": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.claidorhq.com/mcp/claidor-mcp"]
    }
  }
}
```

For sandbox:

```json
{
  "mcpServers": {
    "Claidor Sandbox": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.claidorhq.com/mcp/claidor-sandbox"]
    }
  }
}
```

### Codex

Add the following to your `~/.codex/config.toml`:

```toml
[features]
rmcp_client = true

[mcp_servers.claidor]
type = "http"
url = "https://mcp.claidorhq.com/mcp/claidor-mcp"
```

Then run:

```sh
codex mcp login claidor
```

For sandbox:

```toml
[features]
rmcp_client = true

[mcp_servers.claidor_sandbox]
type = "http"
url = "https://mcp.claidorhq.com/mcp/claidor-sandbox"
```

Then run:

```sh
codex mcp login claidor_sandbox
```

### Claude Code

Run the following command:

```
claude mcp add --transport http "Claidor" "https://mcp.claidorhq.com/mcp/claidor-mcp"
```

For sandbox:

```
claude mcp add --transport http "Claidor Sandbox" "https://mcp.claidorhq.com/mcp/claidor-sandbox"
```

### ChatGPT

MCP is only available for paid users in beta on ChatGPT web, by enabling Developer Mode.

Once Developer Mode is enabled, go to _Settings_ → _Connectors_ and add the MCP server using `https://mcp.claidorhq.com/mcp/claidor-mcp`.

For sandbox, use `https://mcp.claidorhq.com/mcp/claidor-sandbox` instead.

### Claude Desktop

Go to _Settings_ → _Connectors_ and click _Add custom connector_.

Name it "Claidor" and add `https://mcp.claidorhq.com/mcp/claidor-mcp` as the server URL.

For sandbox, use `https://mcp.claidorhq.com/mcp/claidor-sandbox` as the server URL instead.

Save, and click _Connect_ to connect to your Claidor organization.
