## The product

**Caisra** is the name (decided 15 September; it was Faiser for two
days, Maties and Swens before). The app is Messages: each conversation
is an agent, five message kinds, every action on the computer asks
first, text arrives as texts and only speech streams, one computer.
`docs/product/direction.md` is the record; §0 lists what keeps an old
name as an internal identifier.

The desktop app (`desktop/`) is the vendored LobsterAI (NetEase Youdao,
MIT) on the OpenClaw engine v2026.6.1 (source checkout at
`/home/user/Claidor/openclaw`, patched by
`desktop/scripts/patches/v2026.6.1/`, thirty-one patches; ours are
`openclaw-file-tools-ask-first.patch` and `zzz-caisra-identity.patch`).
No string a person or the agent can read says LobsterAI, NetEase, Youdao
or OpenClaw. Developer log tags are `[Engine…]`. The server
(`server/polar/desktop`) serves the account protocol, the metered model
proxy, TTS, the skill store and the kit store.

## What is unrun, and what to read when it runs

1. **Electron with Playwright.** Does Chromium write `DevToolsActivePort`
   under `userData`? Log line: `[AgentBrowserHost] driver=playwright` or
   `driver=devtools`. If devtools, the switch did not take.
2. **Voice.** Needs the Mac build (the workflow runs
   `scripts/build-whisper.sh` first). Composer placeholder says
   "Downloading the voice model" then "Listening".
3. **Claude Code.** On by itself in `electron:dev` when `claude` is
   installed. Log lines, in order: `[ClaudeCode] on: development build,
   claude at …`, `[EngineConfigSync] model=claude-cli/…`, then per send
   `[ClaudeCode] route=fast|strong model=…`. The 16 September fault
   ("Package model information is temporarily unavailable") is gone from
   the code path; what is still unknown: whether the engine wants an
   auth profile first; whether the runtime adapter renders CLI-backend
   events cleanly; whether the approval card survives
   `--permission-prompt-tool stdio`. The engine has a separate
   credential-lifting path (`external-cli-sync.ts`, spoofs
   `user-agent: claude-cli/…`); we never enable it and the founder knows
   it exists.
4. **Routing.** Whether `sessions.patch` honours a `claude-cli/…` model
   override. Log: `sessions.patch` beside the send.
5. **Composio.** Needs `COMPOSIO_API_KEY` set on the server (Render).
   The app carries no key. Connect opens Composio's sign-in and polls
   the toolkit until active; a 503 on the card means the server has no
   key yet.
6. **DoorDash itself.** Never driven. The prompt, the click wait and the
   snapshot cap are all tested with fakes only.
7. **Onboarding, step one (16 September, review 55).** Sign in on a
   fresh install and Yodo plays. Pick "Leave a riddle" or "Change my
   theme"; press Allow; macOS asks its own question once. Log lines:
   `[Onboarding] riddle left in Notes (…)` or `[Onboarding] appearance
   set to dark|light`; a failure logs `[Onboarding] <task> failed:` with
   the reason the person was shown. To play it again, clear
   `onboardingDoneAt` from `app_config`.

## Tooling that works here

- Node 24 must be on PATH:
  `export PATH=/tmp/claude-0/-home-user-Claidor/3310ae3b-3263-5e76-83ec-7ff8ae30b247/scratchpad/node24/bin:$PATH`.
- Gates, from `desktop/`: `npx tsc --noEmit -p tsconfig.json`,
  `npx eslint --ext ts,tsx --report-unused-disable-directives --max-warnings 0 <files>`,
  `npm run compile:electron`, `npx vitest run <paths>`. The full suite
  has 14 files that fail only because `better-sqlite3`'s native binding
  is built for another Node; that is the machine, not the code.
- Harness: `npx vite build --config harness/vite.config.ts` (~50 s), then
  `node harness/shoot.mjs [screens]`, `node harness/live.mjs open|delete`,
  `node harness/shoot-canvas.mjs`.
- Engine patch workflow: `git -C openclaw worktree add <scratch> HEAD`,
  run `scripts/apply-openclaw-patches.cjs <scratch>` for a clean base,
  edit the real checkout, `diff -rq` the two to list files, `git diff
  --no-index` per file into a `.patch`, fix the `diff --git` headers,
  add a strong validator in the script, re-apply on a fresh base to
  prove it, remove the worktree.
- Chromium for tests: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
  whisper.cpp built in the scratchpad; the tiny model and `jfk.wav`
