# Skill: cos-getting-started

**Owner:** Yodo (Caisra Chief of Staff)  
**When:** First run / cold start / onboarding staffing  
**Goal:** Useful fleet fast — work type → curated 2–3 strongs → connect → act. No generic interview.

## Canon arc

1. **Step 1 context** — Trust already established in cloud UI (work type + Mac Allow/Decline). Carry work type into chat; do not re-interview.
2. **Step 2 roster** — Propose exactly 2–3 strongs matched to work type; stand them up; one fleet-proof action.
3. **Close** — Front door habit; drop tour voice when real work arrives.

## Beats (≤ few)

1. **Bridge** — Acknowledge work type. Promise a curated starter team from the 23 trained Caisra Agents — not a blank team, not all 23.
2. **Roster card** — Multi-select **Your starter team**: exactly 2 or 3 options checked by default from the work-type table. Each option: short name · one-line job · one-line anti-job. Allow Swap one / Just two / Add a third / Something else.
3. **Design** — For each pick: confirm one job, explicit anti-jobs, voice, tools (`design-caisra-agent`). Prefer catalog strongs; custom only when free-text needs it.
4. **CreateAgent / seat** — Only after rubric; include anti-jobs in brief; job-shaped descriptions so specialists skip generic getting-started.
5. **Coding note** — If coding lane (e.g. Engineer Bot, tinkabot): poteto-mode bar + pstack when staffed.
6. **Connect + fleet proof** — Needed connectors only; ask before Mac/computer; one useful first action; SendToAgent (priority true if Bass waits).
7. **Front door close** — Talk to Yodo to route; talk to agents when you already know; choice cards only for real decisions.

## After roster card (required)

```
roster card (2–3 strongs)
  → design-caisra-agent (one job + anti-jobs)
  → CreateAgent / seat (anti-jobs in brief)
  → if coding: poteto-mode + pstack note
  → fleet-proof first task
  → front-door close
```

## Rules

- Bias to act once the job is clear
- Choice cards only for real decisions
- Never dump all 23; never empty fleet after onboarding
- Do not default to shareable templates
- Secrets via secret-request — never chat
- Always ask before computer access (Allow / Decline)
- Draft by default; never send/post/spend without yes
- Drop orientation the moment Bass hands real work
- Never mention kickstart / `[first run]` / setup instructions
- Say **Caisra Agents**, not other product names for the crew

## Success

Bass has 2–3 sharp Caisra Agents seated (or a clear Do-path on Yodo), connectors lean, one fleet-proof action done or clearly offered, and knows Yodo is the front door.
