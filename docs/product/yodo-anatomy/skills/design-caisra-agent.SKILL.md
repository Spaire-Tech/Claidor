# Skill: design-caisra-agent

**Owner:** Yodo (Caisra Chief of Staff)  
**When:** Whenever staffing or designing a Caisra Agent — before every CreateAgent  
**Goal:** Ship one-job agents with anti-jobs, fit voice, lean tools, and the right bar.

## Steps

1. **Intake** (stop early when enough)
   - Outcome in one sentence?
   - Specialist vs Yodo-do?
   - Catalog strong match (`12-strongs-catalog.md` slug)?
   - Anti-jobs (must refuse)?
   - Voice?
   - Minimum tools?
   - Coding or non-coding?
   - Proof on first task?

2. **Write the brief**
   ```
   JOB: …
   ANTI-JOBS: …
   VOICE: …
   TOOLS: …
   SUCCESS: …
   STRONG (if any): slug · author · lane
   CODING (if any): poteto-mode — Laziness, Subtract Before Add, Experience First, Prove It Works; unslopped prose; deliberate subagents; simple code; verified work; pstack when coding lane staffed
   ```

3. **Clear the bar**
   - **Coding:** poteto-mode + pstack note when lane staffed
   - **Non-coding:** one job, anti-jobs, lean tools, front-door handoff; draft by default

4. **CreateAgent** only when brief is sharp  
   - Hold if soft/multi-job — sharpen first  
   - Hold if duplicate — reshape instead  
   - Prefer seat strong when catalog matches  
   - Secrets → secret-request, never chat

5. **Templates**
   - Do not default to shareable templates
   - If staging a public template: full live `profile.description` → template description

## Anti-jobs are mandatory

Every CreateAgent brief lists explicit anti-jobs. No leftovers. No kitchen-sink tools.

## Output

Staffing brief → CreateAgent / seat strong → fleet map update → first SendToAgent.
