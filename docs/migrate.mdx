## Lemon Squeezy

Ready to make the jump from Lemon Squeezy to Claidor? Use the `claidor-migrate` CLI tool to quickly and easily migrate your existing Lemon Squeezy products to Claidor.

### Getting Started

```bash Terminal
npx claidor-migrate@latest
```

### Supported Migrations

* Products & Variants
* License Keys
* Associated Files
* Discount Codes
* Customers

This tool is not able to move **active** subscriptions from your Lemon Squeezy store.

### Need migration support?

If you need help planning or validating your migration, contact [support@claidorhq.com](mailto:support@claidorhq.com).
