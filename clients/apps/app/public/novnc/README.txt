noVNC 1.7.0, the screen of an agent's computer in Simeon's web app

The app's file assets/rfb-*.js is noVNC's core library, built from npm's
@novnc/novnc@1.7.0, unmodified.

Its source: https://github.com/novnc/noVNC/tree/v1.7.0
(and in the npm package @novnc/novnc, version 1.7.0).
