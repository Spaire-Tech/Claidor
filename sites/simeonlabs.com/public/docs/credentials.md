# Credentials Store and secure sign-in

The Credentials Store keeps the logins and details your agents need for sign-ins and sign-ups, without you typing them into the chat.

## What you can save

Open **Settings › Credentials Store** on the Mac or iPhone.

- **Logins:** a name, the website, the username or email, and the password. Add a hint like "use this for the supplier portal" to tell Simeon when to use it.
- **Contact info:** your full name, email, phone and address, for forms and sign-ups.
- **Cards** aren't kept here. Payments go through Link, which pays with a one-time card; see [Connect apps](/docs/connectors).

A saved password only shows after Face ID or Touch ID.

## How a sign-in is filled

When a page on an agent's computer asks for a login you've saved, the agent asks to fill it. You confirm, and the computer types it in. The agent never sees the password.

## 1Password

If you connect 1Password, the agent looks there first at a sign-in. A card asks you to **Fill with 1Password**, confirmed with Face ID or Touch ID, and the computer types the username, the password and the one-time code when the login has one.

## Codes and anything else

For a one-time code sent to your phone, or anything not saved, the agent asks with a form in the chat. What you type is masked and goes straight to the page.
