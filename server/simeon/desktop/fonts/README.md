# The API's own font

`geist-400.woff2` is Geist Regular from the `geist` package 1.5.1
(`dist/fonts/geist-sans/Geist-Regular.woff2`), the package the web app sets
its words in. The titles on the pages this host draws in a browser wear it,
as the web app's "Log in or sign up" does (`../page_heading.py`). It is
under the SIL Open Font License (`OFL.txt`, the package's own copy).
